# 客户管理 · 隐私授权记录 产品需求文档（PRD）

> 路由：`#/customer/privacy-auth`　｜　页面规格：`docs/page-specs/客户管理-隐私授权记录.md`

---

## 一、背景与目标

### 1.1 背景

C 端用户在 APP / PC 端同意隐私政策、用户服务协议及各项系统权限（位置、相机等）时，会产生授权记录。监管检查、客诉或协议改版时，需要在后管快速查到「谁、何时、在哪个终端、对哪个协议版本或权限」做过同意，作为隐私合规的举证依据。

&nbsp;

### 1.2 目标

1. 在 `客户管理 → 隐私授权记录` 提供授权记录的只读查询能力，支持按客户、终端、同意类型、协议版本、时间组合筛选。
2. 与「通用配置 → 隐私服务协议管理」打通：点击某版本的「同意人数」直接跳入本页，查看该版本的同意明细。
3. 支持按当前查询条件导出，用于线下归档或对外提交：监管检查、客诉举证时需要提供书面 / 文件形式的授权凭证，在线查询页面无法直接作为材料提交。

## 二、术语与概念


| 概念     | 说明                                                  |
| ------ | --------------------------------------------------- |
| 授权记录   | 用户的一次同意行为，一行一条；同一客户对不同类型、不同版本的每次同意各占一行              |
| 同意类型   | 用户同意的对象：协议类（隐私政策、用户服务协议）或权限 / 个人信息使用类（位置、相机等），共 8 种 |
| 终端     | 产生授权的端：APP / PC                                     |
| 版本号    | 用户同意时的协议版本，对应「隐私服务协议管理」中的版本，如 `V2.1`                |
| 先筛选后查询 | 进入页面不自动加载数据，需点击「查询」后才返回结果                           |

## 三、用户与场景


| 角色      | 场景                        | 使用功能              |
| ------- | ------------------------- | ----------------- |
| 合规 / 法务 | 监管检查、客诉举证，需证明某客户在某时同意过某协议 | ==按客户 + 时间查询、导出== |
| 运营 / 产品 | 协议改版后，查看新版本的同意情况          | ==从协议管理跳入，按版本查询== |
| 客服      | 客户咨询「我是否授权过某权限」           | 按手机号 / 客户ID 查询    |


核心用户故事：

1. 作为合规人员，我要输入客户手机号和时间段，查出该客户全部授权记录并导出，以便提交给监管或用于客诉答复。
2. 作为产品经理，我在协议管理里点击 V3.0 的同意人数，希望直接看到哪些客户、在哪个端、何时同意了 V3.0。

## 四、需求范围总览

```
客户管理 → 隐私授权记录
├── 查询区（7 个条件 / 查询 / 重置）
├── 结果提示条（条数 + 条件描述）
├── 授权记录列表（只读 / 分页）
├── 导出（按当前条件）
└── 外部入口：隐私服务协议管理 → 同意人数 → 带 ?version= 跳入并自动查询
```

本页为只读页面：无新增、编辑、删除，无弹窗、抽屉、详情页。

## 五、功能需求

### 5.1 入口


| 入口       | 路径                                                  | 进入后状态                    |
| -------- | --------------------------------------------------- | ------------------------ |
| 菜单       | 客户管理 → 隐私授权记录（位于「注销申请管理」与「客户分析」之间）                  | 不自动查询，表格显示「请添加筛选条件后查询数据」 |
| 隐私服务协议管理 | 列表点击「同意人数」→ `#/customer/privacy-auth?version=<版本号>` | 先重置查询区，再将版本号填入「版本号」并自动查询 |


页面以多页签打开，标题「隐私授权记录」；切换页签保留已查询的结果。

### 5.2 页面结构

自上而下：

1. **页头**：左侧标题「隐私授权记录」，右侧「导出」按钮。
2. **查询区**：4 列栅格，7 个条件（第一行 4 个、第二行 3 个），下方「查询」「重置」按钮。
3. **结果提示条**：查询后显示；未查询时不显示。
4. **数据表格**：7 列，带边框，无勾选列、无操作列。
5. **分页条**：常驻显示。

### 5.3 查询条件

全部可空，多个条件之间为「且」关系。


| 序号  | 标签     | 控件                           | 占位 / 选项                        | 默认值                | 匹配规则                    |
| --- | ------ | ---------------------------- | ------------------------------ | ------------------ | ----------------------- |
| 1   | 客户ID   | 文本框                          | 请输入客户ID                        | 空                  | 模糊包含，原样子串匹配             |
| 2   | 客户昵称   | 文本框                          | 请输入客户昵称                        | 空                  | 模糊包含，忽略空格与大小写           |
| 3   | 手机号    | 文本框                          | 请输入手机号                         | 空                  | 模糊包含，忽略空格（可只输号码段，也可带区号） |
| 4   | APP/PC | 下拉单选，可清除                     | 全部、APP、PC                      | 全部                 | 精确匹配；「全部」或清空 = 不限       |
| 5   | 同意类型   | 下拉单选，可清除                     | 全部 + 8 个类型（见 §6.1）；随 APP/PC 联动 | 全部                 | 精确匹配；「全部」或清空 = 不限       |
| 6   | 版本号    | 文本框                          | 请输入版本号                         | 空（从协议管理跳入时为带入的版本号） | 模糊包含，忽略空格与大小写           |
| 7   | 时间区间   | 日期范围（仅日期 `YYYY-MM-DD`，分隔符 ~） | 开始日期 / 结束日期                    | 空                  | 按同意时间的日期部分比较，含两端；可只填一端  |


- **终端与同意类型联动**：APP/PC 选「PC」时，同意类型下拉只保留「全部」「隐私政策」「用户服务协议」；若已选的是 APP 专属类型（位置、相机等），自动清空回「全部」。APP/PC 为「全部」或「APP」时显示全部 8 个类型。
- 文本类条件提交前去掉首尾空格。
- 查询区内按 Enter 等同点击「查询」。
- 日期选择：第一次点击设起点，第二次设终点；终点早于起点时自动交换。

### 5.4 列表字段

按**同意时间倒序**，列宽可拖拽，单行显示、超长截断。


| 序号  | 列名     | 字段          | 格式与示例                                       |
| --- | ------ | ----------- | ------------------------------------------- |
| 1   | 客户ID   | customerId  | 20 位数字，如 313532                             |
| 2   | 客户昵称   | alias       | 超长省略号，如 矿山设备管家                              |
| 3   | 手机号    | phone       | `+区号 号码`，如 +86 13982033231                  |
| 4   | APP/PC | terminal    | APP / PC                                    |
| 5   | 同意类型   | consentType | 如 个性化广告                                     |
| 6   | 版本号    | version     | 如 V2.1                                      |
| 7   | 同意时间   | consentTime | `YYYY-MM-DD HH:mm:ss`，如 2026-10-02 21:25:17 |


### 5.5 操作


| 操作  | 位置        | 行为                                               |
| --- | --------- | ------------------------------------------------ |
| 查询  | 查询区下方，主按钮 | 按当前条件查询；页码回到第 1 页；刷新提示条、表格和分页。不填任何条件也可查询，返回全部记录  |
| 重置  | 查询区下方     | 清空文本框和日期，下拉恢复「全部」；页面回到未查询状态；**不触发查询**            |
| 导出  | 页头右侧      | 未查询时提示「请先查询数据后再导出」；已查询时按当前条件导出全部结果（不仅当前页），列与表格一致 |
| 分页  | 表格下方      | 每页行数 10 / 20 / 50 / 100，默认 20；修改后回到第 1 页         |


### 5.6 结果提示条

格式：`共查询到 N 条授权记录（条件：……）`，N 加粗。条件按下列顺序拼接，用「；」分隔，只列出已填的项：

1. 客户ID 含「xxx」
2. 昵称 含「xxx」
3. 手机号 含「xxx」
4. 终端 = APP / PC
5. 同意类型 = xxx
6. 版本号 含「xxx」
7. 同意时间 {开始或「不限」} ~ {结束或「不限」}

未填任何条件时显示「（未设置筛选条件，返回全部记录）」。

### 5.7 分页信息

格式 `{起} - {止} / {总数}`，如 `1 - 20 / 260`；无数据时为 `1 - 0 / 0`，翻页按钮全部置灰。首页 / 末页时对应翻页按钮置灰。

## 六、数据规则

### 6.1 同意类型


| 同意类型    | 分类     | 适用终端   |
| ------- | ------ | ------ |
| 隐私政策    | 协议     | APP、PC |
| 用户服务协议  | 协议     | APP、PC |
| 位置      | 系统权限   | APP    |
| 相机      | 系统权限   | APP    |
| 无线数据    | 系统权限   | APP    |
| 头像使用    | 个人信息使用 | APP    |
| 个性化广告   | 个人信息使用 | APP    |
| 其他APP活动 | 个人信息使用 | APP    |


### 6.2 其他字段取值

- 终端：APP、PC。
- 版本号：对应「隐私服务协议管理」中的协议版本，原型样本为 V1.0、V1.2、V2.0、V2.1、V2.5、V3.0、V3.2。

### 6.3 业务规则

- 授权记录只增不改，后管不提供修改或删除入口。
- 用户每同意一次（含协议改版后重新同意）即新增一条，历史记录保留。

## 七、状态与边界


| 状态  | 触发         | 提示条        | 表格           | 分页               |
| --- | ---------- | ---------- | ------------ | ---------------- |
| 未查询 | 刚进入页面、点击重置 | 不显示        | 请添加筛选条件后查询数据 | `1 - 0 / 0`，全部置灰 |
| 有结果 | 查询返回 ≥ 1 条 | 共查询到 N 条…… | 展示当前页数据      | 正常翻页             |
| 无结果 | 查询返回 0 条   | 共查询到 0 条…… | 暂无符合条件的数据    | `1 - 0 / 0`，全部置灰 |


- 查询中表格显示加载态。
- 时间区间只填开始日期 = 该日及以后；只填结束日期 = 该日及以前（含当天 23:59:59）。
