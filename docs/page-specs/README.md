# 页面规格

迁移前从旧版 HTML 原型（`sanvist-github/Mysany-pc/`）逐页提取的规格说明：页面结构、原文文案、校验规则、交互细节、本地存储和示例数据。新工程以这些规格为验收依据。

- 规格中的文件路径、行号指向旧原型目录，仅作溯源用。
- 每份规格最后一节「原型中的疑似缺陷或不一致」只做记录。新工程中：
  - 业务规则和文案原样保留（即使各页之间不一致）；
  - 因外壳统一而自然消失的问题（各页顶栏写死、提示框无样式等）不再单独处理；
  - 明显的缺陷已修正，代码里有「修正原型缺陷：……」注释。
- 规格之后的需求变更不回写到规格里，见 `docs/requirements/`（例如吊装规划入口改为工作台快速链接）。
