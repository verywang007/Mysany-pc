## 7. 弹窗：添加客户认证

- 标题：**`添加客户认证`**（宽 600）。
- 顶部蓝色提示条 `.tn-info-tip`（字 `#2c7df0`、底 `#e8f4ff`、蓝色圆 `!`）：`请输入完整的客户编号，系统将自动验证其有效性`
- 输入行（网格：输入框自适应 + 92px 按钮）：
  - 标签 `客户编码`（红 `*`），`input#tn-auth-code`，placeholder **`请输入D365客户编码`**；有错误时加 `.bad` 红框。
  - 按钮 `验证`（普通按钮，高 36，与输入框对齐 margin-top 27）。
- 输入框下方状态行（12px）：错误 `● {error}`（`#f04134`）；成功 `● {ok}`（`#00ad65`）；二者只显示其一，错误优先。
- 验证成功后显示客户信息卡 `.tn-verify-card`（底 `#f8f8f9`，圆角 10，3 列网格）：客户名称、客户编码、客户类别、客户分类、国家/地区、电话、邮箱、地址（空值 `-`）。
- 底部按钮：`取消`、`提交认证`（primary）。
- 打开时聚焦客户编码输入框。

**验证（点「验证」或在输入框按 Enter）**：每次都重渲染整个弹窗。
1. 取输入 trim 后的值；先清空 `verified`、`ok`。
2. 为空 → 错误 `请输入D365客户编码`。
3. 不在本地字典 `VERIFY_CUSTOMERS` 中 → 错误 `未查询到有效的客户信息`。
4. 命中 → 清空错误，`verified = 拷贝`，成功文案 `客户编码有效`，显示信息卡。
- 验证阶段**不检查是否已认证**。

**提交认证**：
1. 取当前输入 trim 值。
2. 若尚未验证，或已验证的编码 ≠ 当前输入（验证后又改了输入）→ 错误 `请先验证客户编码`（成功文案清空，**信息卡不清空**，仍显示上次验证的客户）。
3. 若列表中已存在相同 `customerCode` → 错误 `该客户编码已完成认证`（信息卡保留）。
4. 否则：记录 = 拷贝验证结果，`id = 'auth-' + Date.now()`，`creationDate = 当前时间 'YYYY-MM-DD HH:mm:ss'`；`unshift` 入列表，保存，`authPage = 1`，关闭弹窗，重渲染，toast **`客户认证添加成功`**。

可验证的编码（本地字典，3 个）见第 9.4 节；其中 `0214007279` 已在默认列表中，验证会显示「客户编码有效」，但提交会报「该客户编码已完成认证」。

## 9. 数据与 localStorage

### 9.1 键一览

| 常量（本页） | 键名 | 本页读 | 本页写 | 组织管理页（`organization.js`） |
|---|---|---|---|---|
| `STORE_KEY` | `ms_tenant_management_demo` | 初始化 | 保存联系人、转让负责人、添加/删除认证 | 不读不写 |
| `OWNER_KEY`（组织页中叫 `TENANT_OWNER_KEY`） | `ms_tenant_owner_id` | 初始化时作为 ownerId 的候选来源 | **每次页面加载都写**（`= state.data.tenant.ownerId \|\| 'u0'`）；转让时写 | **只读**：加载组织数据时，若该键有值，覆盖根组织（`node.root === true`）的 `leaderId`；组织页从不写此键 |
| `ORG_STORE_KEY` | `ms_org_management_demo` | 初始化时（作为 ownerId 的最后候选）读 `[0].leaderId` | 转让时，若已存在且为非空数组，改写 `[0].leaderId` 后整体写回 | 组织页主存储（组织树数组），组织页各种编辑操作时写 |
| — | `ms_open` / `ms_collapsed` / `ms_route` | 外壳 | 外壳（同角色管理页） | 同 |

### 9.2 初始化 `loadData()`（ownerId 的决定顺序）

```
saved = JSON.parse(localStorage['ms_tenant_management_demo'])
if saved 且 saved.tenant 存在 且 saved.authentications 是数组:
    if !saved.tenant.ownerId:
        saved.tenant.ownerId = localStorage['ms_tenant_owner_id']
                              || ms_org_management_demo[0].leaderId
                              || 'u0'
    使用 saved
else:
    data = clone(DEFAULT_DATA)
    data.tenant.ownerId = localStorage['ms_tenant_owner_id']
                         || ms_org_management_demo[0].leaderId
                         || 'u0'（DEFAULT_DATA 中的值）
然后：localStorage['ms_tenant_owner_id'] = state.data.tenant.ownerId || 'u0'
```

要点：
- **本页已保存过数据时，以本页存储里的 `ownerId` 为准**，`ms_tenant_owner_id` 与组织数据不会反过来覆盖它。
- 默认数据**不写入** `ms_tenant_management_demo`（直到第一次保存）；但 `ms_tenant_owner_id` 在每次打开本页时都会被写入。
- 若存储解析失败或结构不符，静默回退默认数据。

### 9.3 双向同步方向总结
- **租户页 → 组织页**：转让负责人时写 `ms_tenant_owner_id`，并直接改写 `ms_org_management_demo[0].leaderId`（仅当组织页已产生过存储）。即使组织数据尚未存储，组织页下次加载也会从 `ms_tenant_owner_id` 读到新负责人，覆盖根组织负责人。
- **组织页 → 租户页**：组织页不提供修改根组织负责人的入口，也不写 `ms_tenant_owner_id`；租户页仅在本页无已保存 ownerId 时才会参考组织数据 `[0].leaderId`。
- 组织数量 / 用户数量 / 设备数量**不同步**。

## 12. 原型中的疑似缺陷或不一致

1. 需求描述里常提到的 `TENANT_OWNER_KEY` 只是组织管理页里的常量名；本页对应常量叫 `OWNER_KEY`，两者都指向 `ms_tenant_owner_id`。
2. 同步根组织时写的是 `ms_org_management_demo` 数组的**第 0 个元素**，而组织页读取时按 `node.root === true` 判断根节点；两边判定根节点的方式不同（默认数据中二者恰好一致）。
3. 组织页不写 `ms_tenant_owner_id`，且组织页每次加载都用该键覆盖根组织负责人，因此根组织负责人实际只能由租户页决定；README 中「同步根组织」只有单向。
4. 本页每次加载都把自身 `ownerId` 写入 `ms_tenant_owner_id`；本页一旦有存储，其 ownerId 永远优先，外部改动该键在本页无效。
5. 负责人 id 不在 `TENANT_USERS` 中时（如组织数据中的 u6/u8/u9 或任意值），页面回退显示 5656，但 `ownerId` 仍保留原值；转让弹窗的「当前负责人」也显示 5656，并把 5656 从候选中排除。
6. `TENANT_USERS`（10 人）与组织页 `USERS`（13 人：多 u6、u8、u9）、角色页 `USERS`（11 人）不一致；「用户数量」显示 12，与任何一份名单都对不上；「组织数量」4 恰与组织页默认组织数一致，但不随组织增删变化。
7. 手机号无格式校验；区号 `select` 必有值，`!code` 分支实际永远不成立；手机号错误时只给手机号输入框标红，区号下拉不标红。
8. 转让弹窗未选负责人报错后，重新选择不会清除红框和错误文字；转让无二次确认。
9. 添加认证：验证阶段不判断重复，已认证的 `0214007279` 会显示「客户编码有效」，提交时才报「该客户编码已完成认证」。
10. 验证后修改输入再提交，报「请先验证客户编码」，但下方仍显示上一次验证成功的客户信息卡；报「已完成认证」时信息卡也保留。
11. 客户编码输入框在验证阶段不清空错误状态；`input` 事件只更新 `codeInput`，红框和错误文字直到下一次验证/提交才更新。
12. 列表「删除」按钮为蓝色普通链接，与其他页面红色危险链接风格不一致；删除无数量下限（可删到 0 条）。
13. 说明卡标题「什么是客户认证？」与第一个说明块的小标题完全重复。
14. 文案混用「客户编码」与「客户编号」：表头/字段用「客户编码」，弹窗标题「客户编号详情」「删除客户编号」、提示条「请输入完整的客户编号」、说明文案用「客户编号」。
15. 点击遮罩不能关闭弹窗（Esc 可以）。
16. 未加载 `cookies.css`，toast 没有背景、内边距、阴影；`.toast{justify-content:center}` 对非 flex 元素无效；toast 无类型图标。
17. 顶栏租户名「2603181012测试客户」、用户名「5656」、角标「10」写死，与工作台（`DB.user` / `DB.tenant` 为「旺是旺旺的旺」）不一致；语言、租户下拉点击无反应；退出登录无确认。
18. 页签状态不持久化，刷新总回到「租户管理」。
19. 菜单「吊装规划」在本页显示为 box 回退图标。
