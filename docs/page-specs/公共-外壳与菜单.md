### 3.2 下拉通用机制（wb.js L233–245，app.css L86–97）

- `popup(host, html, width)`：先关闭所有 `.pop`，再创建 `div.pop` 追加到触发元素 `host` 内部；可选 `width`（px）。
- 定位：`position:absolute; top:calc(48px - 4px)=44px; right:0`（右对齐触发项），`min-width:150px`，白底、圆角 6px、`--shadow-pop`、`padding:4px 0`、`cursor:default`。
- 关闭：`document` 上任意点击 → `closePops()`；下拉内部点击 `stopPropagation`，所以点下拉内部不会关闭（除非选项自己调用关闭）。
- 再次点击同一触发项：不会切换关闭，而是**销毁后重新打开**（每次触发都 `closePops()` + 新建）。
- 同一时间只存在一个下拉。
- 菜单项 `.pop-item`：`padding:9px 16px; font-size:13px; color:--ink-1`，hover 底 `--bg-soft`，当前项 `.on` 文字 `--theme`。
- 无 Esc 关闭（代码中未体现）。

### 3.7 退出登录

- 使用简易弹窗 `dialog()`（wb.js L58–83）：标题 `退出登录`，描述 `确定要退出当前账号吗？`，按钮 `取消` / `确定`（主按钮）。
- `确定` → `location.href = '登录.html'`。
- `取消` / 点遮罩 → 仅关闭。
- **不清除任何 localStorage**（`ms_route`、`ms_open`、`ms_collapsed`、`ms_settings` 均保留），因此重新登录进入 `工作台.html` 时会回到退出前的页面与菜单状态。

## 4. 通用弹窗与 Toast（外壳级公共组件）

### 4.1 简易弹窗 `dialog(opt)`（wb.js L58–83，app.css L418–426）

- 参数：`title`、`desc`（可选，`<p>`）、`input`（传了即渲染输入框，值为初始值）、`ph`（placeholder，默认 `请输入`）、`onOk(value)`。
- 结构：遮罩 `.mask`（`rgba(0,0,0,.45)`，居中，z 400）> `.dlg`（宽 400px，`max-width:92vw`，`padding:22px 24px`，圆角 8px）> `h3`(16px) / `p`(13px `--ink-3`) / `input.ipt` / 底部 `.dlg-ft`（右对齐，按钮 `取消`、`确定`）。
- 有输入框时自动 `focus()` + `select()`。
- `确定` → 关闭后回调 `onOk(input.value.trim())`（无输入框时回调值为 `true`）。
- `取消`、点遮罩空白处 → 关闭，不回调。
- 在遮罩内按 `Enter` → 等同确定（keydown 监听在遮罩上，需焦点在弹窗内）。
- **无 Esc 关闭、无 × 按钮**。
- 校验失败时弹窗已经关闭（先 `m.remove()` 再回调），只能重新打开。

### 4.2 Toast（wb.js L48–55，cookies.css L139–153）

- 容器 `#toasts`：`fixed; top:64px; left:50%` 水平居中，竖向堆叠 `gap:8px`，`pointer-events:none`。
- 单条：白底、`--shadow-pop`、圆角 6px、`padding:9px 16px`、13px，入场动画 `.2s`（自上 8px 淡入），**2600ms 后移除**。
- 类型：`ok`（对勾，`#2a9d4e`，默认）、`info`（圆 i，`--blue`）、`err`（圆 ×，`#f5222d`）。

### 4.3 按钮与开关（cookies.css）

- `.btn`：`width:100%; height:36px; border-radius:4px; border:1px solid --line-2`，白底；hover 文字与边框变 `--theme`。
- `.btn-p`：底色/边框 `--theme`，白字，500，`margin-bottom:10px`；hover `#ab0009`。
- 弹窗底部按钮在 `.dlg-ft`/`.dlg-ft2` 中被改为 `width:auto`。

### 5.4 展开/收起与记忆

- 点击分组一级行（`data-grp="1"`）：
  - 折叠态下**不响应**（直接 return，交给浮层）；
  - 否则切换该分组在 `state.open` 数组中的存在 → 写 `localStorage.ms_open` → 重新渲染。
  - 多个分组可同时展开（**非手风琴**）。
- 点击无子菜单的一级行或二级行 → `go(k)`。
- `go(k)` 时，会把包含该子项的父分组**自动加入** `state.open`（只加不减）并写 `ms_open`。
- 刷新后按 `ms_open` 恢复展开状态。

### 5.5 折叠态（64px）与悬停浮层（wb.js L145–183，app.css L169–183）

折叠态样式（`body.collapsed`）：

- 侧栏宽 64px，Logo 区宽 64px（`padding-left:12px`），主体 `margin-left:64px`。

- 选中样式仍生效：无子项的选中项保留红底+左红条；有选中子项的分组图标变红。

悬停浮层 `#flyout`：

- 仅折叠态生效。鼠标 `mouseover` 任一一级行时：
  - 有子菜单：头部 `.ft` 显示一级 label（12px，`--ink-3`，`padding:8px 18px 6px`，下分割线），下面列出所有二级 `.fi`；
  - 无子菜单：只显示一个 `.fi`，文案为该一级 label（无头部）。
  - 当前路由对应 `.fi` 加 `.on`（文字 `--theme`）。

  - `top = max(56, min(行.top, window.innerHeight − 浮层高度 − 10))` px。
- 隐藏：鼠标离开 `#menu` 或离开浮层后 **180ms** 延迟隐藏；移入浮层时取消隐藏计时。
- 点击浮层项 → 立即隐藏浮层 → `go(k)`。
- 折叠态下直接点击无子菜单的一级图标也会 `go(k)`。

## 6. 路由与页面跳转

### 6.1 机制（wb.js L188–228）

- **无 URL 路由**，不改 hash / history；当前页只存在 `state.route` 与 `localStorage.ms_route`。
- `LABEL` 表：遍历 `DB.menu`，一级与二级的 `k → label`。
- 启动校验：若 `ms_route` 的值不在 `LABEL` 中（如线上删掉的旧菜单），重置为 `workbench` 并回写。
- 启动最后调用 `go(state.route)` 恢复页面。

`go(k)` 顺序：

1. `state.route = k`；写 `ms_route = k`。
2. 自动展开父分组，写 `ms_open`。
3. 若 `k` 为独立页 → `location.href` 跳转并 return（见 6.2）。
4. 否则切换四个 `section` 的 `hidden`；占位页标题 `#ph-t` = `LABEL[k] || '模块'`。
5. `document.title = (LABEL[k] || '工作台') + ' - MySANY'`。
6. 重新渲染菜单；`window.scrollTo(0,0)`。

## 7. localStorage 键

| 键 | 值类型 / 示例 | 读时机 | 写时机 |
|---|---|---|---|
| `ms_route` | 字符串，菜单 k，如 `"workbench"` | wb.js 启动（L89），缺省 `workbench` | 每次 `go()`（L201）；启动校验不合法时（L196） |
| `ms_open` | JSON 字符串数组，展开中的一级 k，如 `["enterprise","audit"]` | wb.js 启动（L90），缺省 `[]` | 点击分组（L137）；每次 `go()`（L208） |
| `ms_collapsed` | `"1"` / `"0"` | wb.js 启动（L91），`=== '1'` 为折叠 | 点击折叠按钮；**启动时 `applyCollapsed()` 也会写一次**（L177） |
| `ms_settings` | 见《公共-设置弹窗.md》 | 打开设置弹窗时 | 设置弹窗保存 / Cookie 抽屉确认 |

- 以上键与各独立页、`协议变更.html` 共用。
- `mysany_lang` 不被 wb.js 读写。
- 内存状态（不持久化）：`state.auditKey`、`state.sortDesc`、`state.pcTab`、`state.pwMode`、角标已读、语言文字、`DB.user` 的修改。

## 8. 原型中的疑似缺陷或不一致

1. **返回循环**：`go()` 跳转独立页前已把 `ms_route` 写成 `tenant` / `organization` / `user-management` / `role-management` / `lift-plan`；之后若通过浏览器「后退」或直接打开 `工作台.html`，启动时 `go(ms_route)` 会**立即再次跳回该独立页**，无法停留在工作台（除非在独立页里点了其他菜单改写了 `ms_route`）。
2. 退出登录不清除任何本地状态；重新登录后落在上次页面（若上次是独立页，会直接跳到独立页）。
3. README 写「15 个一级菜单」，`DB.menu` 实际 16 个（多了「吊装规划」）。
4. `data.js` 的 Cookie 清单把 `ms_collapsed`/`ms_open`/`ms_route`/`ms_settings`/`mysany_lang` 描述为 Cookie 并写了「180 天」「会话结束时」等持续时间，但实际都是 `localStorage`，无过期；`ms_route` 标「会话结束时」实际永久保留。
5. 菜单 `path` 字段在 wb.js 中完全未使用；部分子项（审核任务、知识库、考勤*、自助服务、重卡车队运营全部子项）没有 `path`。
6. 「全部已读」只隐藏角标：下拉标题仍显示 `通知 (10)`，消息行无已读样式；刷新后角标重新出现。
7. 语言切换只改顶栏文字并弹 Toast，不翻译、不持久化；与登录页 `mysany_lang`（值为 `zh-CN` 等代码）不联动。
8. 租户下拉选项点击无任何反应，且下拉不会关闭。
9. 消息行 `cursor:pointer` 但无点击行为。
10. 下拉不能通过再次点击触发项关闭（只会重开）；无 Esc 关闭。
11. 简易弹窗无 Esc、无 ×；Enter 确认依赖焦点在弹窗内（无输入框的退出确认框打开时无焦点，Enter 无效）。
12. `ms_open` 使用 `JSON.parse` 读取且无 try/catch，值损坏会导致脚本整体报错。
13. `ms_collapsed` 在启动时即被写入，即使用户从未操作。
14. 「自助服务」是一个无说明的纯红色块，与其他占位页风格不一致。
15. `#modal-root`、`--theme-bg-2`、`ICONS.service/parts/globe` 定义但未使用。
16. 折叠态装饰图形宽 96px 大于侧栏 64px，代码中未做裁剪处理。
17. 折叠浮层 `top` 下限为 56px（与顶栏 48px 不一致，留了 8px 余量）；角色管理页的同类实现用的是 54px，两处不统一。
18. 折叠态隐藏了 PRO 角标，浮层中也不显示 PRO。
19. 头像是 emoji `🧑`，不同系统渲染不一致。
