### 3.4 底部渐隐 `.pu-fade`（L240-246，CSS L49-57）

- 0 高度占位，`::before` 绝对定位 30px 高渐变（透明 → #fff），`pointer-events:none`。
- 当正文未滚到底（`scrollTop + clientHeight < scrollHeight - 2`）时 `.pu-dlg` 加 `.has-more`，渐隐显示（opacity 过渡 .2s）；内容不溢出或已到底时隐藏。
- 触发：初始化、正文 `scroll`、`window resize`。
- **不强制读到底**：勾选与按钮不依赖是否滚动到底。

### 3.7 打开 / 关闭动画

- 打开：插入 DOM → 强制 reflow → 加 `.is-open`。遮罩 `opacity 0→1`（`.24s ease`）；弹窗 `translateY(12px) scale(.985) → none`（`.26s cubic-bezier(.32,.72,0,1)`）。
- 关闭 `close(done)`（L256-261）：移除 Esc 捕获监听与 resize 监听 → 去掉 `.is-open`（反向过渡）→ **260ms 后**移除 DOM 并执行回调 `done`。

## 4. 不可关闭规则

| 操作 | 结果 |
|---|---|
| 点击遮罩空白（`e.target === mask`） | 不关闭，toast `请先阅读并选择同意或拒绝`（info） |
| 按 `Esc` | 不关闭；在 `document` **捕获阶段**监听（`addEventListener('keydown', onKey, true)`），`preventDefault + stopPropagation`，toast `请先阅读并选择同意或拒绝`（info） |
| 阅读弹窗或二次确认弹窗打开时按 `Esc` | `onKey` 检测到 `.pu-docmask` 或 `.pu-confirm` 存在则直接 return（不提示、不阻止）；这两个子弹窗本身**没有 Esc 处理**，因此 Esc 无任何效果 |
| 关闭按钮 | 无 |

唯一出口：「同意」成功，或「拒绝 → 仍然拒绝」。

## 11. 原型中的疑似缺陷或不一致

1. **「隐私政策」与「隐私协议」混用**：正文写《隐私政策》（两处），勾选行、阅读弹窗标题、退出态文案写《隐私协议》；`DOCS.privacy` 的 note 又写「隐私政策」。
2. 勾选顺序（用户服务协议在上）与登录页（隐私协议在上）相反。
3. 存储键 `mysany.policy.agreedVersion` 只写不读；演示页每次进入都弹窗，未实现版本比对。键名风格（点分）与其他键（`ms_settings`、`mysany_lang`、`ms_route`）不一致。
4. 「同意」按钮置灰态仍是 pointer 光标、可点击（有意为之以触发抖动），与登录页 `disabled` + `not-allowed` 的处理方式不同。
5. 正文第 3 段写「如果您勾选同意**或继续使用** MySANY 平台，即表示您知情并接受」，但实际不勾选无法继续使用，文案与机制不符。
6. 二次确认文案说「本次会话将退出」，但退出态只是覆盖层：不清除任何登录相关存储、也未跳转；刷新页面会再次弹出更新提示（因演示页每次都弹）。
7. 「仍然拒绝」后主弹窗先淡出 260ms 才出现退出态，期间背景工作台短暂可见、可交互。
8. 阅读弹窗与二次确认弹窗均不响应 Esc，且主弹窗的 Esc 拦截在它们打开时放行但无人处理——Esc 在子弹窗中完全无效（与工作台设置弹窗 Esc 可关闭不一致）。
9. 阅读弹窗的 `‹` 返回箭头与 `×` 功能完全相同，均为关闭。
10. 无焦点管理：弹窗打开时不移动焦点、无焦点陷阱，键盘 Tab 可聚焦并操作背后的工作台（如搜索框、菜单）。
