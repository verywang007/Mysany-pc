## 2. 外壳（顶栏 / 侧栏）——仅记录与 `wb.js` / `工作台.html` 的差异

外壳规格由他人统一编写，这里只记录本页实现与工作台的不同。

### 2.1 顶栏 HTML 差异

| 项 | 工作台（`工作台.html` + `wb.js`） | 吊装规划（`吊装规划.html` + `lift-planning.js`） |
|---|---|---|
| 元素类型 | `div.hd-item` | `button.hd-item.lift-hd-button`（`type="button"`） |
| id | `t-bell` / `t-lang` / `t-tenant` / `t-user` | `lp-bell` / `lp-language` / `lp-tenant` / `lp-user` |
| 角标数字 | HTML 写 10，启动时 `wb.js` L701 改为 `DB.messages.length` | HTML 写死 `10`（L19），JS 不改 |
| 租户名 / 用户名 | 启动时 `wb.js` L699-700 改为 `DB.tenant.current.name` / `DB.user.name` | HTML 写死「旺是旺旺的旺」（L27、L31），JS 不改 |
| aria | 无 | 铃铛 `aria-label="通知"`；SVG 带 `aria-hidden="true"` |
| 字号 / 颜色 | `.hd-item` 13px、`var(--ink-2)` #4e5969 | `.lift-hd-button { font: inherit; color: inherit }` 在 `app.css` 之后加载、同优先级，**覆盖了** `.hd-item` 的 13px 和颜色 → 实际为 body 的 14px、`var(--ink-1)` #1d2129；hover 仍为主题红（`.hd-item:hover` 优先级更高） |
| 按钮默认内边距 | 无（div） | `.lift-hd-button` 只重置了 background / border / font / color，**未重置 padding**，浏览器默认按钮 padding 仍在 |

### 2.2 顶栏交互差异

| 按钮 | 工作台 | 吊装规划（`lift-planning.js`） |
|---|---|---|
| 铃铛 | 弹出消息下拉（通知列表 +「全部已读」） | L166：toast `暂无新通知`（kind `info`） |
| 语言 | 弹出语言下拉（简体中文 / English），可切换 | L167：toast `当前语言：简体中文`（info） |
| 租户 | 弹出租户下拉 | L168：toast `当前租户：旺是旺旺的旺`（info） |
| 用户 | 弹出下拉：个人中心 / 设置 / 退出登录 | L169：`e.stopPropagation()` 后直接 `goToRoute('personal')` → 写 `ms_route=personal` 并跳 `工作台.html`；**没有「设置」「退出登录」入口** |
| 点击空白关闭下拉 | 有（document click → closePops） | 无下拉，无此逻辑 |

### 2.3 侧栏主导航差异（`lift-planning.js` L64-102 vs `wb.js` L97-183）

- **菜单项**：两者都渲染 `DB.menu`（`data.js` L25-83），共 16 个一级项，最后一项为 `{ k: 'lift-plan', icon: 'lift', label: '吊装规划', path: '/standard/liftPlanning/liftPlanning' }`（L82）。菜单项一致。
- **图标**：本页 `ICONS`（L11-29）只含菜单用到的 17 个（home/device/audit/training/screen/report/personnel/project/monitor/maintain/repair/cost/video/ent/truck/lift/box），逐个比对 path 与 `wb.js` **完全一致**；差别仅在本页 SVG 多了 `aria-hidden="true"`。分组展开箭头 `.mi-arw`：本页**缺 `stroke-linecap="round"`**（wb.js 有）。
- **data 属性名**：wb.js 用 `data-k` / `data-grp`；本页用 `data-nav` / `data-group`（一级）、`data-route`（二级 / 浮层）。
- **选中态**：本页写死 `selfOn = !kids && m.k === 'lift-plan'`（L68），即只有「吊装规划」一级项带 `.mi.on`（浅红底 #fdeced + 红字 + 左侧 3px 红条，样式来自 `app.css`）。本页**不渲染** `.si.on`、`.grp.has-on`、浮层 `.fi.on`（「吊装规划」无子项，所以视觉上无差别）。
- **分组展开**：点分组行切换 `state.navOpen` 并写 `ms_open`；折叠态下点分组行无反应（与 wb.js 一致）。
- **路由跳转** `goToRoute(k)`（L75-82）：
  - `lift-plan` → 直接 return（不刷新、不提示）；
  - `tenant` / `organization` / `user-management` / `role-management` → 跳对应 `企业服务-*.html`；
  - 其余任何 key → `localStorage.setItem('ms_route', k)` 后跳 `工作台.html`。
  - 与 wb.js `go()` 的差别：本页**不会**自动把包含目标子项的分组加入 `ms_open`；跳企业服务页时**不写** `ms_route`（wb.js 会先写）。
- **折叠态浮层**（L91-100）：
  - 隐藏延迟 **150ms**（wb.js 180ms）；
  - 定位 `top = max(54, min(r.top, innerHeight - fly.offsetHeight - 8))`（wb.js 为 `max(56, min(r.top, innerHeight - h - 10))`）；
  - 点击浮层项后**不先隐藏浮层**（wb.js 会 `fly.hidden = true`）；在浮层点「吊装规划」时 `goToRoute` 直接 return，浮层保持显示，直到鼠标移出 150ms 后才隐藏。
  - 查找菜单用 `Array.prototype.find`（wb.js 用 filter）。
- **折叠按钮**：`button.tg.lift-icon-button`（wb.js 是 `div.tg`），多 `aria-label="收起或展开导航"`；同样未重置 padding。点击切换 `body.collapsed`、写 `ms_collapsed`，折叠时立即隐藏浮层。
- **toast 实现**：本页 `toast()`（L59-62）**不带图标**（wb.js 按 ok/info/err 插入 SVG 图标），2600ms 后移除。并且本页**没有加载 `.toast` 样式**（见缺陷）。
- **esc()**：本页额外转义 `'` 并兼容 null/undefined（L9）；wb.js 不转义单引号。
- **未加载 cookies.js**：工作台里的 Cookies 偏好中心 / 设置弹窗本页均不可用。

```js
  slide: 0,             // 0 | 1 | 2

  navCollapsed: localStorage.getItem('ms_collapsed') === '1',        // 主导航是否折叠
  projects: [ { name: '测试', time: '2026-10-09 14:00:00' } ]         // { name: string, time: string }
};
```

- 页签、SMART LIFT 菜单、轮播张数、顶栏名称、角标都写死在 HTML / JS，不来自 `data.js`。
- 无任何网络请求。

初始化顺序（L172）：`applyCollapsed()` → `renderMenu()` → `renderSlides()` → `renderProjects()`。

## 8. localStorage

| 键 | 读 | 写 | 值 |
|---|---|---|---|

## 10. 原型中的疑似缺陷或不一致

只记录，不做修复建议。

1. **toast 无样式**：本页没加载 `cookies.css`（`.toasts` / `.toast` 定义所在），`lift-planning.css` 也没有定义。`#toasts` 是 body 末尾的普通块元素，toast 会按文档流排在主区之后（主区 `min-height: 100vh`），不固定、不浮在顶部，一般需要滚到页底才看得到，且可能被 fixed 侧栏遮住左侧。本页几乎所有交互的反馈都依赖 toast。
2. **toast 不带图标**：本页 `toast()` 没有 ok / info / err 图标，与 wb.js 不同；传入的 `info` 只体现在 class 上。
3. **页签吸顶可能无效**：`.lift-tabs` 设了 `position: sticky; top: 0`，但父级 `.lift-main` 设了 `overflow: auto`，又只有 `min-height: 100vh`、没有固定高度，它成了一个不会滚动的滚动容器，页面实际在 body 上滚动，sticky 不会生效（按 CSS 规则推断，未实测）。即使生效，`top: 0` 也会落在 fixed 顶栏（48px，z-index 100）下面。
4. **顶栏字号 / 颜色与工作台不一致**：`.lift-hd-button { font: inherit; color: inherit }` 覆盖了 `.hd-item` 的 13px 和 `--ink-2`，实际变成 14px、`--ink-1`；按钮默认 padding 没有重置。
5. **顶栏行为与 PRD「壳架一致性」不符**：铃铛、语言、租户只弹 toast，不出下拉；用户按钮直接去个人中心，没有「设置」「退出登录」。PRD 第四节写「顶栏与左侧主导航…行为与工作台一致」。
6. **顶栏数据写死**：角标 10、租户名、用户名写在 HTML 里，不读 `DB.messages` / `DB.tenant` / `DB.user`；工作台里「全部已读」后的角标隐藏状态也不会带到本页（工作台本身也不持久化）。
7. **浮层点「吊装规划」后不收起**：折叠态下浮层点当前页项，`goToRoute('lift-plan')` 直接 return，浮层不隐藏；wb.js 点击浮层项会先隐藏。
8. **外壳参数与 wb.js 有细微差异**：浮层隐藏延迟 150 vs 180ms；浮层 top 下限 / 底边留白 54/8 vs 56/10；`.mi-arw` 缺 `stroke-linecap="round"`；跳回工作台时不自动展开目标子项所在分组；跳企业服务页时不写 `ms_route`。
9. **取消按钮不重置路由**：只跳 `工作台.html`，不改 `ms_route`，回去不一定是工作台首页。
10. **模块页签与 SMART LIFT 菜单只是假切换**：`state.tab` / `state.ln` 只写不读；标题固定「欢迎使用」，选「创建项目」「受力计算」等内容都不变。重复点同一项会重复弹 toast。
11. **页签「工作台」与主导航「工作台」重名**：页签里的「工作台」不跳转主应用工作台，只切换选中态，容易混淆。另有「项目设置」「设置」两个相近页签。
12. **轮播名不副实**：3 张同图同时并排显示，只有选中放大、高亮；没有自动播放、箭头、滑动。底部 `‹ ›` 像翻页箭头，但只是不可点击的文字。
13. **选中色不统一**：SMART LIFT 菜单和视图切换选中用 `#1677ff`（antd 默认蓝），页签、圆点、取消 hover 用主题红 `#c6000b`；`#1677ff` 和 app.css 的 `--blue`（#2a78d6）也不一致。
14. **文字色不收敛**：同一页面并存 `#333`、`#222`、`#1f2329`（app.css 主文字为 `#1d2129`），灰色有 `#8a9099`、`#9aa0a8`、`#b7bdc6` 三种，都不是 app.css 的 `--ink-*`。
15. **主导航折叠时 SMART LIFT 栏反而变窄**：`body.collapsed .lift-side { width: 200px }`，可用空间变大时左栏从 220 缩到 200，方向与直觉相反。
16. **≤960px 时 SMART LIFT 栏直接隐藏**：没有替代入口，4 个菜单项在窄屏下不可达。窄屏下 9 个页签也没有溢出处理。
17. **品牌图标与菜单图标不一致**：`.lift-brand-icon` 里的吊钩 SVG path 与主导航 `ICONS.lift` 不同。
18. **`lift-page-body` 类无定义**：body 上的类在 CSS / JS 中都没有被引用。
19. **项目列表无空态**：`state.projects` 为空时只留白，没有空状态文案；只有 1 条写死的数据。
20. **`ms_open` 解析无防护**：`JSON.parse` 未包 try/catch，值损坏会让整页脚本报错。
21. **加载时写 `ms_collapsed`**：`applyCollapsed()` 在初始化时也会写一次 localStorage（与 wb.js 相同，只是记录）。
22. **PRD 与代码 / 目录不一致**：
    - PRD 写的路径是 `Mysany-pc/mysany-login-local/工作台.html`、`.../吊装规划.html`，实际文件在 `Mysany-pc/` 根目录，没有 `mysany-login-local` 子目录。
    - PRD 章节编号从「二」直接跳到「四」，缺「三」（按「首页框架」推测应是页面内容说明，PRD 完全没写 SMART LIFT 首页的页签、菜单、轮播、最近项目、取消按钮）。
    - PRD 1.2 写「保留 MySANY 顶栏（消息/语言/租户/用户）…可与其他模块互相跳转」，但顶栏下拉功能在本页缺失（见第 5 条）。
    - PRD 说图标为「吊钩造型线性图标（1.8 描边、24×24 视图）」，与主导航 `ICONS.lift` 相符；页内品牌图标是另一种画法（描边 2）。
    - PRD 文档标题为「重卡车队运营 · 吊装规划」，但代码里「吊装规划」是与「重卡车队运营」平级的一级菜单，不在其分组下（PRD 2.1 正文也写的是一级菜单，标题与正文措辞不一致）。
    - `data.js` 给 `lift-plan` 配了 `path: '/standard/liftPlanning/liftPlanning'`，PRD 没提这个线上路由。
23. **README 未同步**：README 写「15 个一级菜单」，列表里没有「吊装规划」，「目录」一节也没列 `吊装规划.html` / `lift-planning.*` / `吊装规划-PRD.md`；`data.js` 实际有 16 个一级菜单。
