## 1. 页面结构（自上而下）

容器 `.wb`：`padding:26px 30px 40px`。

1. 顶部区 `.wb-top`（flex，`gap:24px`，`margin-bottom:26px`）
   - 左：问候 `.wb-hi`
     - `h1#greet`：问候语（26px，700，`letter-spacing:.5px`，`margin-bottom:10px`）
     - `p`：`统一掌握资产与运营全局，快速推动关键事项落地。`（14px，`--ink-3`）
   - 右：工具 `.wb-tools`（`gap:12px`，`padding-top:8px`）
     - 搜索框 `.search`
     - 齿轮图标 `#wb-gear`
2. 区块「计划保养」`.sec`
   - 标题行：红竖条 + `计划保养` + 右侧 `查看全部 ›`
   - 4 列卡片网格 `#mt-grid`
3. 区块「审核概览」`.sec`
   - 标题行：红竖条 + `审核概览` + 右侧 `进入审核 ›`
   - 5 列卡片网格 `#au-grid`
   - 排序条 `.ev-bar`：右对齐 `发生时间 ▾`
   - 事件列表 `#ev-list`
4. 区块「快速链接」`.sec`
   - 标题行：红竖条 + `快速链接`（无右侧链接）
   - 4 列卡片网格 `#qk-grid`

区块通用样式：

- `.sec`：`margin-bottom:26px`。
- `.sec-h`：flex 居中，`margin-bottom:14px`；`.bar` 3×14px、`--theme`、圆角 2px、右边距 9px；`h2` 15px 700。
- `.more`：`margin-left:auto`，13px，`--ink-3`，hover `--theme`，右箭头 svg 11×11，`gap:3px`。
- `.grid`：`gap:16px`；`.g4` 4 等分，`.g5` 5 等分。
  - 视口 ≤1400px：`.g5` → 3 列；
  - 视口 ≤1100px：`.g4`、`.g5` → 2 列。

## 2. 问候语（wb.js L305–307）

- 文案：`{问候}，{DB.user.name}`（中文全角逗号），当前为 `下午好，旺是旺旺的旺` 等。
- 按**本机时间** `new Date().getHours()` 取值：

| 小时 h | 问候 |
|---|---|
| 0 ≤ h < 6 | `凌晨好` |
| 6 ≤ h < 9 | `早上好` |
| 9 ≤ h < 12 | `上午好` |
| 12 ≤ h < 14 | `中午好` |
| 14 ≤ h < 18 | `下午好` |
| 18 ≤ h ≤ 23 | `晚上好` |

- 计算时机：页面启动时（`renderWorkbench()`）、个人中心修改姓名成功后（重新调用 `renderWorkbench()`）。**不随时间自动刷新**，切换路由回工作台也不重算。
- HTML 中静态文案 `下午好，旺是旺旺的旺` 仅为占位，会被覆盖。

## 3. 搜索与设置（wb.js L363–368，app.css L219–233）

### 3.1 搜索框 `#wb-search`

- 宽 430px，高 34px，圆角 17px（胶囊），边框 `--line-2`，`padding:0 16px 0 38px`，13px；
- 左侧放大镜 svg 15×15（`left:14px; top:9px`，`--ink-4`）；
- placeholder：`搜索设备`（色 `--ink-4`）；
- focus：边框 `--theme`，外发光 `0 0 0 2px rgba(198,0,11,.08)`。
- 交互：**仅响应 Enter**（keydown）。值 `trim()` 后：
  - 非空 → Toast（info）`搜索设备：{关键字}`
  - 为空 → Toast（err）`请输入设备关键字`
- 不跳转、不过滤、不清空输入框；无搜索按钮、无联想（代码中未体现）。

### 3.2 齿轮 `#wb-gear`

- `title="设置"`，svg 18×18，`--ink-3`，hover `--theme`。
- 点击 → Toast（info）`工作台设置（本地演示）`。**不打开**设置弹窗。

| k | n | fresh | label |

## 6. 事件列表与排序（wb.js L332–347、L355，app.css L278–299）

### 6.1 数据

`DB.auditList`（data.js L102–114），以审核卡片 k 为键的数组：

```ts
type AuditEvent = {
  title: string;  // 如 '故障码 | 空滤阻塞(P072)'
  fresh: boolean; // true 显示「新」标签
  sub: string;    // '设备号 · 机型'
  time: string;   // 'YYYY-MM-DD HH:mm:ss (UTC+7)'，带时区后缀
};
```

- `device`：3 条（09-28、09-27、09-26，均 `UTC+7`）；
- `maint`：3 条（09-27 18:52:53、09-27 18:52:52、09-26 18:56:03，均 `UTC+8`），标题为长文本 `保养超期 | 超时保养提醒 — 已超过保养日期，超期 781h，请尽快安排保养，如需远程支持立即预约。` 等；
- `fuel` / `geo` / `check`：空数组。

### 6.2 排序

- 排序条 `#ev-sort`：文案 `发生时间` + 实心三角 svg 10×10；整体 13px `--ink-3`，hover `--theme`；所在 `.ev-bar` 右对齐，`padding:14px 0 6px`。
- 默认 `state.sortDesc = true`（降序，三角朝下）。
- 点击 → 取反 → 仅重绘列表；升序时 `.asc` 使三角 `rotate(180deg)`（朝上，.2s 过渡）。
- 排序键：`time.slice(0, 19)`（只取 `YYYY-MM-DD HH:mm:ss`，**忽略时区后缀**）按字符串比较；相等保持 0。
- 排序方向在切换审核卡片后**保留**（不重置）；不持久化。
- 原数据数组不被修改（先 `slice()` 复制）。

### 6.3 列表项

- `.ev`：flex，`gap:16px`，`padding:15px 0`，项间上边线 `--line`（首项无）。
- 左 `.ev-main`：
  - 标题行 `.ev-t`（13px，`--ink-1`，可换行）：6×6 蓝色圆点（`--blue`，上距 6px）+ 标题文本 + `fresh` 为真时蓝色标签 `新`（`.ev-tag`：`--blue-bg` 底，11px，圆角 3px，`padding:1px 5px`）。
  - 副标题 `.ev-sub`：12px，`--ink-3`，上距 7px，左缩进 14px。
- 右 `.ev-time`：12px，`--ink-3`，不换行，底部对齐；显示完整 `time`（含时区）。
- 列表项**不可点击**（代码中未体现）；无分页、无「加载更多」，全部展示。
- 空状态：`<div class="ev-empty">暂无数据</div>`（`padding:44px 0`，居中，`--ink-4`，13px）。

## 8. 数据与状态汇总

| 状态 | 位置 | 默认 | 持久化 |
|---|---|---|---|
| `state.auditKey` | wb.js L92 | `'device'` | 否 |
| `state.sortDesc` | wb.js L93 | `true` | 否 |
| 问候语 / 姓名 | `DB.user.name` | `旺是旺旺的旺` | 否（个人中心可改，仅内存） |

- 本页**不读写**任何 localStorage 键（路由键见外壳文档）。
- 渲染时机：`renderWorkbench()` 在启动时调用一次、修改姓名后再调用一次；`go('workbench')` 只切显隐，不重渲染。

## 9. 原型中的疑似缺陷或不一致

1. README 写问候语为「早上好 / 上午好 / 下午好 / 晚上好」四种，代码实际有六种（多「凌晨好」「中午好」）。
2. 问候语只在启动/改名时计算，长时间停留跨时段不会更新。
3. README 写「未设置策略 0」，data.js 实际 label 为 `未设置保养策略`。
4. 审核卡片数量（设备异常 19、新 17；维保事项 85、新 84）与列表实际条数（各 3 条）不一致，列表无分页 / 加载更多。
5. 排序忽略时区后缀（`UTC+7` 与 `UTC+8` 混用时按本地字面时间比较）；当前每类内部时区一致，但数据结构允许混用。
6. 齿轮 `title="设置"`，但点击只弹 Toast，不打开顶栏「设置」弹窗。
7. 搜索仅支持 Enter，无按钮；只弹 Toast，不做任何搜索。
8. 计划保养卡片、事件列表项均不可点击；只有区块标题的「查看全部」可跳转。
9. 「查看全部」「进入审核」及全部快速链接目标都是占位页。
10. 审核卡片选中、排序方向刷新后丢失。
11. `.au-new` 用 `a.fresh` 真值判断，`fresh` 为 0 时隐藏；而事件 `.ev-tag` 用布尔 `fresh`，两处字段含义不同（数量 vs 布尔）。
