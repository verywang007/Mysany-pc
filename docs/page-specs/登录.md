### 3.7 Cookies 设置入口行

- 位置：两行协议下方、登录按钮上方（`登录.html` L149-156）。
- 结构：`.login-cookie`（flex，gap 8px，13px，`margin:-8px 0 24px`，可换行）

  - 中：`已启用 {n} / {m} 类`
  - 英：`{n} / {m} categories enabled`

## 5. 校验规则与提交流程（`app.js` L175-187）

表单 `#basic`：`autocomplete="off" novalidate`。提交（点击按钮或输入框内回车）：

1. `preventDefault()`。
2. 按钮 `disabled` → 直接 return（无提示）。
3. 任一协议未勾选 → `alert(needAgree)`，return。
4. 若当前为**密码登录** Tab：
   - 用户名取 `trim()` 后值，密码取**原值（不 trim）**。
   - 与 `ACCOUNT = { user: 'admin', pass: '123' }`（L9）严格比较（区分大小写）；不一致 → `alert(badLogin)`，return。输入框不清空、无红框。
5. **验证码登录 Tab 不做任何校验**（仅需两框非空即可让按钮可用），直接跳转。
6. 跳转：`location.href = HOME`，`HOME = '工作台.html'`（L10）。不写入任何登录态。

错误提示形态：全部为浏览器原生 `alert()`，无行内错误、无 toast。

## 6. 初始化顺序（L189-196）

1. 读语言（见 §7）。
2. 预填 `basic_username = 'admin'`、`basic_password = '123'`。
3. 两个协议复选框置为勾选。
4. `applyLang()`（替换文案、写 `mysany_lang`、刷新 Cookies 状态）。
5. `refresh()` → 默认情况下登录按钮**可用**（红色实心）。

## 9. 原型中的疑似缺陷或不一致

1. **页面闪烁英文**：HTML 静态文本为英文、`<html lang="en">`，默认语言却是中文，JS 执行前会短暂显示英文。
2. `<title>`（`登录 - MySANY`）与二维码 `title="Scan qr code login"` 不参与 i18n；英文模式下标签页标题仍为中文。
3. `needAgree` 提示基本不可达：未勾选任一协议时按钮已 `disabled`，提交第 2 步就 return，第 3 步 `alert(needAgree)` 实际无法触发。
4. 验证码登录 Tab 无任何校验：手机号、验证码任意非空即可登录进入工作台；也不校验手机号格式。
5. 用户名做 `trim()`，密码不 `trim()`：用户名前后空格会被忽略，密码带空格则登录失败；而按钮可用性判断里密码又是 `trim()` 后判断非空。
6. 错误提示使用原生 `alert()`，而页面已放置 `#toasts` 容器且 Cookies 抽屉使用 toast，两种提示风格并存。
7. 二维码角标、「立即注册」均无点击行为；协议链接只弹 `alert('打开：…')`，没有协议阅读弹窗（工作台设置里有阅读弹窗）。
8. 登录页协议顺序为「隐私协议 → 用户服务协议」，而协议变更弹窗为「用户服务协议 → 隐私协议」，两处不一致。
9. `#lang-trigger` 可 Tab 聚焦（`tabindex=0`），但不响应键盘；`#lang-menu` 的 `role="menu"` 也无键盘导航。
10. `mysany_lang` 在每次进入页面时都会被写入（`applyLang()` 无条件 `setItem`），即使用户从未切换语言。
11. Cookies 抽屉正文固定中文，英文模式下入口为英文、点开后为中文。
12. Cookies 状态在抽屉以 ×、遮罩、Esc 关闭（未保存）时也会重新读取刷新——结果不变，仅记录行为。
13. `html, body { overflow:hidden }` 且卡片固定 533px + 右边距 56px、上下内边距合计 196px：小窗口/小屏高度不足时卡片内容会被裁切且无法滚动。
14. `SourceHanSansCN-Bold`、`DINCondensed-Regular` 两个字体有 `@font-face` 声明，但样式中未使用。
15. 输入框无 focus 态样式（`outline:none` 且无替代）。
16. 登录成功不写入任何登录态，工作台也无从判断是否已登录（直接打开 `工作台.html` 即可进入）——代码中未体现登录态校验。
