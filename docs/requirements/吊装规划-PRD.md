## 一、需求背景与目标

### 1.1 背景

1. 平台现有「重卡车队运营」等模块聚焦于运输车辆运营管理，缺少面向**履带起重机吊装作业**的规划能力入口。
2. 吊装规划（SANY SMART LIFT）作为独立业务系统，需要在 MySANY 平台侧拥有统一入口，用户登录后可直接从左侧导航进入。
3. 首期仅做**入口打通 + 首页框架**：以吊装工作台首页（SMART LIFT 首页）为原型。

### 1.2 目标


| 目标      | 说明                                         |
| ------- | ------------------------------------------ |
| 导航入口统一  | 左侧导航「重卡车队运营」下方新增一级目录「吊装规划」，点击进入吊装规划页面      |
| 与平台壳架一致 | 保留 MySANY 顶栏（消息/语言/租户/用户）与左侧主导航，可与其他模块互相跳转 |


---

## 二、导航与入口

### 2.1 入口

> 2026-10-10 调整：吊装规划**不再作为左侧一级菜单**，改为工作台「快速链接」的入口，替换原来的「项目管理」。

工作台「快速链接」四项依次为：地图监控 / 预警中心 / 设备保养 / **吊装规划**（蓝色图标块，吊钩图标）。点击进入吊装规划页面。


| 项      | 说明                                 |
| ------ | ---------------------------------- |
| 页面 key | `lift-plan`（登记在 `src/config/menu.ts` 的 `HIDDEN_PAGES`，不在侧栏显示） |
| 名称    | 吊装规划                               |
| 图标     | 吊钩造型线性图标（与其他菜单同规格：1.8 描边、24×24 视图） |
| 入口   | 工作台「快速链接」第 4 项；点击进入 `#/lift-planning`        |

## 四、交互与边界规则汇总


| 规则    | 说明                               |
| ----- | -------------------------------- |
| 壳架一致性 | 顶栏与左侧主导航、折叠/展开、折叠态浮层子菜单行为与工作台一致。 |
| 导航选中态 | 吊装规划不在主导航中，页内主导航无高亮项            |


---

## 五、验收标准

1. 登录进入工作台，「快速链接」第 4 项为「吊装规划」，带吊钩图标；左侧导航中没有「吊装规划」。
2. 点击「吊装规划」打开 `#/lift-planning`；页面右下角「取 消」回到工作台。
