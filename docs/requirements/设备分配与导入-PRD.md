## 一、需求背景与目标

### 1.1 背景

1. 组织管理中，**根组织（租户节点）**此前只有「组织成员」一种视图，无法在根节点查看和管理设备，与子组织能力不对齐。
2. 子组织的设备分配表缺少「所属组织」字段，无法判断设备归属；
3. 组织与设备的分配关系、用户与设备的分配关系均缺少**按模板批量导入**的能力，多设备/多用户场景只能逐条勾选。
4. 用户管理工具栏中的「导入」按钮语义不明确，实际导入的是**用户**，与新增的「导入分配」容易混淆。

### 1.2 目标


| 目标          | 说明                                        |
| ----------- | ----------------------------------------- |
| 根节点与子节点能力对齐 | 根组织同样具备「组织成员 / 设备分配」双视图                   |
| 设备归属可视化     | 设备分配表新增「所属组织」列，一眼看清设备归属                   |
| 操作不歧义       | 同一行只出现一个操作：有归属 = 取消分配，无归属 = 分配            |
| 分配可指定组织     | 未分配设备点击「分配」后可选择目标组织                       |
| 分配关系可批量导入   | 组织管理提供「导入」（设备 → 组织），用户管理提供「导入分配」（设备 → 用户） |
| 入口文案明确      | 用户管理的「导入」改名为「导入用户」，并紧随「设备分配」新增「导入分配」      |

## 二、组织管理 · 设备分配

### 3.1 页签结构

- **根组织与子组织统一**展示 `组织成员 | 设备分配` 双页签，样式与交互一致。
- 切换组织节点时页签重置为「组织成员」。
- 工具栏按钮随页签变化：


| 页签   | 工具栏按钮                    |
| ---- | ------------------------ |
| 组织成员 | 批量移除、添加成员                |
| 设备分配 | 批量取消分配、分配设备、**导入**（本期新增） |


### 3.2 设备分配表字段


| 顺序  | 字段   | 说明                                 |
| --- | ---- | ---------------------------------- |
| 1   | 复选框  | 支持当前页全选、批量操作                       |
| 2   | 设备编号 | 如 `SY007CBHC0908`，超长省略号 + 悬浮提示     |
| 3   | 设备类型 | 如：挖掘机、搅拌车、泵车                       |
| 4   | 分配时间 | 取所属组织的分配时间；未分配显示 `-`               |
| 5   | 所属组织 | 根视图展示设备实际归属组织；子组织展示本组织名称；未分配显示 `-` |
| 6   | 操作   | 见 3.3，**同一行只显示一个按钮**               |


列表支持分页，默认每页 10 条（可选 20 / 50）。

### 3.3 数据范围与操作规则


| 场景  | 数据范围         | 操作列                     |
| --- | ------------ | ----------------------- |
| 根组织 | 租户全部设备（含未分配） | 有归属 → `取消分配`；无归属 → `分配` |
| 子组织 | 仅本组织已分配设备    | 统一为 `取消分配`              |


**取消分配**

- 点击后二次确认（单条：`确认取消设备"SY007CBHC0908"的分配吗？`；多条：`确认取消所选 N 台设备的分配吗？`）。
- 解除绑定，删除该设备的分配时间，设备回到根节点设备分钟中未分配状态。
- 在根视图下同样按设备**实际所属组织**解除。

**分配**

- 仅未分配设备出现此入口，点击弹出「选择组织」弹窗（见 3.4）。
- 选择组织并确认后，设备归属该组织，并写入分配时间（当天）。

### 3.4 选择组织弹窗（单台设备分配）

- 标题：`选择组织`；宽度 460px。
- 列表：按组织层级缩进展示全部组织节点，单选（圆形单选态），根组织带「根组织」标签。
- 底部：`取消` / `确定`（未选择组织时置灰不可点）。
- 确认后提示「设备已分配到「组织名」」，列表实时刷新「所属组织」与「分配时间」。

### 3.5 根组织「分配设备」两步向导

根组织点击「分配设备」打开两步弹窗（顶部步骤条 `1 选择组织 —— 2 选择设备`），流程参考用户管理「设备分配」。

**第 1 步：选择组织**


| 项   | 说明                                         |
| --- | ------------------------------------------ |
| 列表  | 组织节点单选，列：组织名称（层级缩进、根组织带标签）、组织编码、上级组织、当前设备数 |
| 搜索  | 按组织名称搜索，支持回车与「搜索」按钮                        |
| 底部  | `已选组织：N` + `取消` + `下一步`（未选组织时禁用）           |


**第 2 步：选择设备**


| 项   | 说明                                                |
| --- | ------------------------------------------------- |
| 列表  | 设备多选，列：设备编号、设备类型、所属组织（展示当前归属）                     |
| 搜索  | 按设备编号或设备类型搜索                                      |
| 提示  | 「已分配的设备将转移至所选组织」——支持把设备从原组织调整到所选组织                |
| 底部  | `为「组织名」分配 N 台设备` + `取消` + `上一步` + `确认分配`（未选设备时禁用） |


**确认分配**

- 将所选设备分配到第 1 步选定的组织。
- 保存后返回当前设备分配页，刷新「所属组织」「分配时间」，并提示「已为「组织名」分配 N 台设备」。

> 子组织的「分配设备」保持单步弹窗（直接选设备，分页 10/20/50，仅可勾选未分配设备），单击即分配至当前组织。

### 3.6 设备导入（工具栏「导入」）


| 项    | 说明                                                       |
| ---- | -------------------------------------------------------- |
| 入口   | 设备分配页签工具栏「导入」，位于「分配设备」之后（根组织、子组织一致可用）                    |
| 弹窗标题 | `导入设备`                                                   |
| 下载模板 | 「下载导入模板」导出 `设备导入模板.csv`                                  |
| 模板字段 | **设备编号、组织1、组织2、组织3、组织4、组织5**（按 2026-10-12 确认：仅表头、无示例行，UTF-8 带 BOM，Excel 可直接打开；组织 1~5 五列供用户填写设备归属组织，更多组织可自行添加「组织6、组织7…」等列） |
| 上传方式 | 虚线框 + 「选择文件」（`accept=".xlsx,.xls,.csv"`）                 |
| 校验结果 | `文件 xxx 校验完成：成功 N 条，失败 0 条`；表格列：行号、设备编号、所属组织、状态（成功）      |
| 保存导入 | 按模板「所属组织」把设备分配到对应组织（已归属其他组织的自动转移），成功提示「设备导入成功，共处理 N 台设备」 |
| 底部按钮 | `取消` + `保存导入`（未选择文件时不显示保存按钮）                             |

## 三、用户管理 · 导入用户 / 导入分配

### 4.1 工具栏调整

按钮顺序调整为：

```text
新增用户 | 导入用户 | 设备分配 | 导入分配 | 邀请记录
```


| 变更          | 说明                      |
| ----------- | ----------------------- |
| 「导入」→「导入用户」 | 仅文案变更，导入对象为用户，逻辑与弹窗保持不变 |
| 新增「导入分配」    | 紧随「设备分配」之后，打开「导入分配」弹窗   |


### 4.2 导入分配弹窗


| 项    | 说明                                                                   |
| ---- | -------------------------------------------------------------------- |
| 弹窗标题 | `导入分配`                                                               |
| 下载模板 | 「下载导入模板」导出 `设备分配导入模板.csv`                                            |
| 模板字段 | **用户姓名、所属组织、型号、设备编号**（附示例行）                                          |
| 上传方式 | 虚线框 + 「选择文件」（`accept=".xlsx,.xls,.csv"`）                             |
| 校验结果 | `文件 xxx 校验完成：成功 N 条，失败 0 条`；表格列：行号、用户姓名、所属组织、型号、设备编号、状态（成功）          |
| 保存导入 | 按「用户姓名」匹配用户、「设备编号」匹配设备，将设备加入该用户的已分配设备（自动去重），成功提示「设备分配导入成功，共处理 N 条记录」 |
| 底部按钮 | `取消` + `保存导入`（未选择文件时不显示保存按钮）                                         |

## 四、交互与边界规则汇总


| 规则      | 说明                                       |
| ------- | ---------------------------------------- |
| 根视图操作安全 | 根视图下的取消分配/导入转移均作用于设备**实际所属组织**，不会误改根组织数据 |
| 分配时间    | 每次建立归属关系时写入当天日期；取消分配时清除                  |
| 向导按钮态   | 未选组织时「下一步」置灰；未选设备时「确认分配」置灰               |
| 搜索      | 弹窗内搜索支持回车与「搜索」按钮，搜索词在重新渲染后回显             |
| 数据持久化   | 所有变更写入 localStorage，刷新页面后保留，无需后端接口       |

## 五、验收标准

**组织管理**

1. 选中根组织，可见「组织成员 / 设备分配」双页签，样式与子组织一致。
2. 根组织设备分配页展示全部 18 台设备，未分配设备「所属组织」「分配时间」显示 `-`。
3. 已分配设备行仅显示「取消分配」，未分配设备行仅显示「分配」，不出现同时展示。
4. 点击未分配设备的「分配」→ 弹出「选择组织」单选弹窗 → 确定后该设备显示目标组织与当天分配时间。
5. 点击「取消分配」→ 二次确认 → 设备回到未分配状态；在根视图操作同样生效。
6. 根组织点击「分配设备」→ 出现两步向导；第 2 步勾选设备后提示「为「组织名」分配 N 台设备」，确认后设备归属该组织。
7. 设备分配页签可见「导入」按钮；点击后弹窗内可下载 `设备导入模板.csv`，按 2026-10-12 确认模板表头为 `设备编号,组织1,组织2,组织3,组织4,组织5`（仅表头、无示例行；组织列可自行扩展）。
8. 选择文件后展示校验结果（行号/设备编号/所属组织/状态），点击「保存导入」后设备按模板组织归属并提示成功。

**用户管理**

9. 工具栏文案为「导入用户」，按钮顺序为：新增用户、导入用户、设备分配、导入分配、邀请记录。
10. 「导入用户」点击后行为与改动前一致。
11. 「导入分配」弹窗内可下载 `设备分配导入模板.csv`，模板表头为 `用户姓名,所属组织,型号,设备编号`。
12. 选择文件后展示校验结果（行号/用户姓名/所属组织/型号/设备编号/状态），点击「保存导入」后对应用户的已分配设备增加且不重复。
